# OneCore AI

Универсальная распределённая AI-экосистема для управления личными устройствами.

**Статус:** проектирование. Реализация OneCore AI ещё не начата.

Поддерживаемые платформы (цель): Windows, Linux, macOS, Android, iOS/iPadOS, Wear OS и Android TV.

Читайте [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md), [AGENTS.md](AGENTS.md) и [план разработки](docs/ROADMAP.md).

Рабочий прототип ChatGPT Wear существует отдельно и **не должен изменяться автоматически**.
