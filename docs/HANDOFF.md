## Цель
Распределённая AI-экосистема Windows/Linux/macOS/Android/iOS/Wear OS/Android TV.
Два устройства работают без обязательного ПК-сервера. Первое доказательство:
Windows ↔ Android, сопряжение, адресные ping/message, аудит, повторная доставка и отзыв.
AI/голос/VPN и системное управление — позднее, с учётом ограничений ОС.

## Реализовано
Python 3.10+ без сторонних пакетов:
- model.py: локальная политика, UUID, адрес, права, срок и набор повторов.
- codec.py: ограниченный UTF-8 JSON v1, строгие поля и UTC-время,
  запрет дублирующихся ключей, неизвестных полей, невалидных типов.
- trust.py: AuthenticatedPeer и TrustGrant; совпадение sender/ключа/прав, отзыв.
  Это API для доверенного адаптера, не криптографическая аутентификация.
- storage.py: SQLite-резервирование command_id до действия, SHA-256 содержимого,
  конфликт при переиспользовании ID с другим содержимым/отправителем.
  Повтор после перезапуска не резервируется заново.
  Состояния accepted/executed/failed/unknown_outcome, однонаправленный переход в terminal.
  Оставшийся accepted после сбоя — не разрешение повторять действие.
  Вызывающий код должен отдельно разрешить неопределённость; automatic recovery нет.
- CI: Windows/Linux × Python 3.10/3.12. Запуск тестов:
  PowerShell: $env:PYTHONPATH = "src"; python -m unittest discover -s tests -v
  Локально 31 тест прошёл на Python 3.12; актуальный CI проверить в PR.

## Ограничения
Сети, TLS/handshake, сопряжения, ключей ОС, клиентов и исполнителя ещё нет.
Журнал не интегрирован с транспортом/политикой; reserve вызывать только после
актуальной аутентификации/авторизации. База на одно целевое устройство.
Журнал содержит digest, ID отправителя и состояние, без текста и секретов.
Это не полный аудит и не хранилище тела результата; схемы миграций/очистки нет.
Тест двух соединений проверяет уникальность записи, а не нагрузку параллельных потоков.
Не обещать exactly-once: внешнее действие и SQLite не атомарны.
JSON-кодек не является стандартом канонизации для подписей.
Не конструировать AuthenticatedPeer из недоверенного JSON.
Передача административной роли и восстановление потерянного администратора пока проект.
