# OneCore AI — прототип: статус

## Реализовано в ветке feature/protocol-foundation

- Модель адресной команды версии 1: UUID, отправитель, получатель, действие, данные, срок действия.
- Чистая функция локальной проверки целевого устройства, разрешённого отправителя, действия, срока и повторов.
- Разрешены только безвредные типы `ping` и `message`.
- Модульные тесты проверки правил.

## Второй этап: сериализация и политика доверия
- Строгий UTF-8 JSON codec команд v1, лимиты и отклонение неоднозначных полей.
- Модель AuthenticatedPeer/TrustGrant и проверка привязки отправителя к ключу,
  правам и отзыву. Это модель политики, не реализация криптографии.
- Контракты и ограничения: [протокол](PROTOCOL.md), [доверие](TRUST_MODEL.md).
- Локальные и CI unit tests проверяют модель, а не реальную связь устройств.

## Не реализовано

- Windows/Android приложения и пользовательский интерфейс.
- Подлинная идентичность устройств, криптография, сопряжение, доверенная передача, журнал и постоянное хранилище.
- Сеть, обнаружение устройств, автоматическое переподключение, очередь и реальное выполнение команд.
- Передача роли администратора, AI, VPN, синхронизация.

**Важно:** функция `evaluate_command` — только пример проверки политики; входные поля отправителя не аутентифицированы. Не применять для управления устройствами до реализации безопасного транспорта, проверки подписей/идентичности и атомарного хранения обработанных ID.

## Локальная проверка

При установленном Python 3.10+ из корня репозитория:

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```

Для PowerShell:

```powershell
$env:PYTHONPATH = "src"; python -m unittest discover -s tests -v
```

Никаких сторонних пакетов не требуется. Код не запускается автоматически при открытии репозитория.

- Ужесточены проверки типов, канонического UUID и структуры payload.
