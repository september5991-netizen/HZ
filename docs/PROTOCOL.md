# Контракт команд v1
Реализован codec.py: encode_command(Command) -> bytes, decode_command(bytes) -> Command.
Декодирование не означает доверие или разрешение на исполнение.

Один UTF-8 JSON object, не более 32768 байт. Все поля обязательны:
version (строго integer 1), command_id (канонический UUID в нижнем регистре),
sender_id и recipient_id (непустые строки до 256 символов), action (ping/message),
payload, expires_at (UTC, формат YYYY-MM-DDTHH:MM:SS.ffffffZ).
ping: payload = {}. message: только text, строка до 4096 символов.
Неизвестные поля, повторяющиеся ключи на любом уровне, NaN/Infinity,
невалидный UTF-8, некорректные типы, даты и непарные суррогаты отклоняются.
Срок проверяется политикой при приёме; истёкшая команда может быть декодирована.
Кодек нормализует время при кодировании, но не является стандартом
канонизации JSON для подписей. Нельзя подписывать произвольные повторные сериализации.

Транспортное кадрирование, подписи, handshake и формат результатов ещё не реализованы.
План результата: command_id + отдельный статус accepted/executed/failed/unknown_outcome.
Пропавший ответ не означает failed; после неопределённого исхода нельзя слепо повторять действие.
Сетевая реализация обязана ограничивать размер кадра до его полного чтения,
время чтения и количество сообщений; текущий кодек получает уже выделенный bytes.
